# RiskReview AI Prototype App

Open `index.html` in a modern browser. The prototype is a self-contained HTML demonstration with no server, external libraries, network calls, authentication or production data.

## Demonstrated workflow
Upload → deterministic validation → AI finding → related-risk comparison → mitigation challenge → authorised human decision → verified agenda → evaluation.

## Scope
Automotive AI is the primary application: ECU, ADAS, connected vehicle, OTA, cybersecurity and supplier governance. Wind-energy condition monitoring demonstrates configuration.

## Important boundary
All records are synthetic. AI recommendations do not approve safety, compliance, suppliers, risk closure, release or investment.
