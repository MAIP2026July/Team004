# Screenshot Capture Guide

Capture screenshots only from the working browser prototype and upload them with these filenames:

1. `01_Risk_Register_Upload.png` - Dashboard and programme input panel
2. `02_Quality_Dashboard.png` - Quality summary and finding counts
3. `03_Risk_Quality_Finding.png` - Original text, explanation and human actions
4. `04_Related_Risk_Comparison.png` - Side-by-side risk comparison
5. `05_Mitigation_Challenge.png` - Existing mitigation and challenge question
6. `06_Human_Decision_Audit.png` - Decision rationale and audit history
7. `07_Verified_Review_Agenda.png` - Meeting agenda generated from verified findings
8. `08_Evaluation_Dashboard.png` - Illustrative evaluation panel

## Capture method

1. Open `app/index.html` in Microsoft Edge or Google Chrome.
2. Select the relevant navigation tab.
3. Use the browser screenshot feature or Windows Snipping Tool.
4. Save the image using the exact filename above.
5. Do not modify scores or labels to appear like measured results.

## Evidence labels

Use these captions in GitHub:

- Clickable prototype
- Synthetic automotive data
- Simulated AI output
- Illustrative metric, not measured result
