# Functional Prototype

This folder contains the clickable RiskReview AI prototype for automotive component New Product Development and New Product Introduction programmes from APQP to Start of Production.

## Prototype status

- **Type:** Clickable browser prototype
- **Data:** Synthetic automotive programme-risk data
- **AI output:** Simulated for workflow validation
- **Decision authority:** Human users retain all consequential decisions
- **Production status:** Not production-ready

## Run locally

1. Open `app/index.html` in Microsoft Edge or Google Chrome.
2. Use the navigation tabs to review the dashboard, findings, related risks, mitigation challenge, agenda and audit evidence.
3. Use the action buttons to accept, edit, reject, link, merge or defer findings.
4. Select **Reset demo** to restore the original synthetic state.

## Product boundary

The prototype does not assign probability or impact, replace DFMEA or PFMEA, approve PPAP, approve Start of Production, or autonomously accept, merge, escalate, close or delete programme risks.
