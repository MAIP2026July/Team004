# 09_Prototype

## Purpose
This folder contains the runnable RiskReview AI front-end prototype, a synthetic enterprise risk register, the demo sequence, limitations and eight screenshots. The prototype reflects the expanded scope while keeping automotive AI as the primary use case and wind energy as a secondary configurable use case.

## Contents
- `App/` – self-contained interactive HTML prototype
- `Screen_Shots/` – ordered evidence of the prototype workflow
- `Demo_Guide.md` – step-by-step demonstration script
- `OEM_Enterprise_AI_Risk_Register-v6.xlsx` – synthetic input, dashboard, decision audit and configuration
- `Prototype_Limitations.md` – explicit technical and governance boundaries

## Start
1. Download and extract the folder.
2. Open `App/index.html` in Microsoft Edge, Google Chrome or Firefox.
3. Follow `Demo_Guide.md`.
4. Use the included workbook when the upload screen requests a file.

## Product boundary
RiskReview AI provides evidence-linked findings and mitigation suggestions. Accept, Modify, Reject and Escalate decisions remain with authorised humans.
