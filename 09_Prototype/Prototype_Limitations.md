# Prototype Limitations

## What the prototype demonstrates

- End-to-end monthly programme-risk review workflow
- Deterministic completeness and date checks
- Simulated AI-assisted semantic findings
- Human accept, edit, reject, link, merge and defer controls
- Verified review-agenda preparation
- Audit-history concept

## What the prototype does not prove

- Production accuracy, fairness, security or scalability
- Actual preparation-time reduction
- Customer willingness to pay
- Integration with enterprise automotive systems
- Performance on confidential or real programme data
- Legal, contractual or regulatory compliance

## Hard-coded demonstration elements

- Programme name and component
- Synthetic risks and evidence
- Example similarity and confidence values
- Evidence-age threshold
- Dashboard totals
- Illustrative evaluation metrics

## Production-configurable elements

- Customer risk taxonomy
- Mandatory fields and APQP milestones
- Evidence-age and similarity thresholds
- Review roles and escalation routes
- Model provider, prompt and rules versions
- Notifications, exports and retention settings
