## 3. Decision Entry Template

| Field | Required content |
|---|---|
| Decision ID | Unique identifier |
| Date | Decision date |
| Decision owner | Accountable person or group |
| Context | Problem or trigger |
| Options considered | Viable alternatives |
| Decision | Selected option |
| Evidence | Data, research or expert input |
| Consequences | Benefits, risks and trade-offs |
| Follow-up | Action, owner and date |
| Status | Proposed, confirmed, superseded or rejected |
