# UX, Workflow and Trust Design

This folder defines how RiskReview AI fits into the automotive programme-risk review workflow.

The artifacts cover:

- Initial PlantUML swimlane workflow
- User journey
- Human-in-the-Loop decisions
- Trust and explainability requirements
- Manual fallback
- Audit and traceability
- Prototype wireframes and screenshots

The initial workflow may be revised after discovery interviews, PRD validation and prototype usability testing.
