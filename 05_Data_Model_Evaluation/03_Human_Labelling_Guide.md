# Human Labelling Guide

## Reviewers
Maharshi Pandit and Swaminathan B. independently label the evaluation sample. Disagreements are discussed and the resolution is documented.

## Cause-event-impact quality
- **Clear:** cause, uncertain event and business/programme impact are understandable.
- **Partial:** one element is weak or implied.
- **Unclear:** the statement is a topic, issue label or unsupported outcome.

## Mitigation alignment
- **Aligned:** action addresses the stated cause or reduces event likelihood/impact.
- **Partial:** action helps but lacks owner, timing, evidence or specificity.
- **Not aligned:** action is generic follow-up or does not address the risk.

## Related risks
Label pairs as duplicate, related-but-distinct, or unrelated. A duplicate label requires materially the same underlying cause-event-impact and decision need.

## Meaning preservation
Compare original and suggested wording. Mark failure if the suggestion adds an unsupported fact, changes ownership, alters the event, changes the impact or turns uncertainty into certainty.

## Evidence freshness
Use a configurable age threshold. For the prototype, any threshold is provisional and must be labelled as such.
