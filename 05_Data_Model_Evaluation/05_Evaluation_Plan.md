# Evaluation Plan

## Objective
Determine whether RiskReview AI improves register readiness and preparation efficiency without changing intended meaning or taking consequential decisions.

## Baselines
- Manual review
- Spreadsheet validation
- Keyword or exact-match duplicate check

## Evaluation stages
1. Verify deterministic rules with known examples.
2. Run offline evaluation on held-out synthetic records.
3. Conduct task-based usability testing with target-role participants.
4. Compare manual and assisted preparation time.
5. Review safety failures and launch blockers.

## Key tests
- Completeness-rule accuracy
- Cause-event-impact agreement with reviewers
- Related-risk precision and recall
- Mitigation-challenge usefulness
- Unsupported-fact rate
- Meaning-change rate
- Useful-finding rate
- Human correction burden
- Agenda traceability

## Evidence status
All thresholds are provisional until measured. Do not report target values as achieved results.
