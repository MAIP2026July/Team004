# Governance RACI

## Purpose

This document assigns accountability for prototype and future-pilot governance. Customer roles remain hypotheses until discovery and pilot contracting confirm the actual organisation structure.

## RACI Legend

- **R:** Responsible for completing the work
- **A:** Accountable for the final decision
- **C:** Consulted
- **I:** Informed

| Activity | Product Manager | NPD Project Manager | APQP Coordinator | Risk Owner | Technical Lead | Data/Privacy Owner | Sponsor |
|---|---|---|---|---|---|---|---|
| Approve product scope | R | C | C | I | C | C | A |
| Approve automotive workflow | C | A | R | C | I | I | I |
| Define mandatory fields | C | A | R | C | C | C | I |
| Approve AI use cases | R | C | C | I | C | C | A |
| Label evaluation data | C | C | R | R | I | I | I |
| Approve evaluation thresholds | R | A | C | I | C | C | I |
| Review AI findings | I | A | R | C | I | I | I |
| Confirm merge, link or keep separate | I | A | R | C | I | I | I |
| Approve pilot data access | I | C | I | I | C | A | A |
| Deploy technical change | C | I | I | I | R | C | A |
| Approve release gate | R | C | C | I | C | C | A |
| Lead incident response | C | I | I | I | R | R | A |
| Approve rollback or restoration | C | C | I | I | R | C | A |
| Approve commercial claims | R | C | I | I | I | I | A |
